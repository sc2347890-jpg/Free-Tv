# FreeTV - APK banane ke steps (phone se)
1. github.com par free account banao -> New repository (naam: freetv).
2. "uploading an existing file" se is zip ke andar ke saare files upload karo (.github folder samet).
3. Upar "Actions" tab -> "Build APK" -> kuchh minute rukho (green tick).
4. Us run par kholo -> neeche "Artifacts" -> FreeTV-APK download karo (zip mein app-release.apk).
5. APK install karo (Settings mein "Install unknown apps" allow karna padega).
